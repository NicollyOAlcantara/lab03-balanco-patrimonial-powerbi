#  Lab 03 — Balanço Patrimonial com Visual de Matriz

Laboratório desenvolvido no **Power BI** como parte dos estudos em análise de dados.

O exercício proposto no curso tinha como foco a construção de um **visual de matriz para um Balanço Patrimonial**. A partir da estrutura apresentada, ampliei o dashboard utilizando conhecimentos adquiridos durante meus estudos na **Data Science Academy**, adicionando indicadores e uma visualização para complementar a análise.

##  Objetivo

Praticar a construção de um dashboard financeiro no Power BI utilizando uma matriz hierárquica e indicadores para facilitar a visualização das informações do Balanço Patrimonial.

##  Dashboard

![Lab 03 - Balanço Patrimonial](lab-03-balanco-patrimonial.png))


O dashboard apresenta:

* **Ativo Total**
* **Passivo + Patrimônio Líquido**
* **Patrimônio Líquido**
* Visual de matriz com estrutura hierárquica das contas;
* Dados distribuídos entre **2019 e 2023**;
* Evolução dos **Lucros Acumulados por ano**;
* Informações de Passivo, Patrimônio Líquido, Capital Próprio, contas circulantes e não circulantes.

## 🛠️ Ferramentas e conhecimentos utilizados

* **Power BI Desktop**
* **DAX**
* **Visual de Matriz**
* **Visualização de Dados**
* **Análise de dados financeiros**

##  Sobre o desenvolvimento

A proposta inicial do laboratório fornecia a estrutura para criação do **visual de matriz do Balanço Patrimonial**.

A partir dos conhecimentos adquiridos ao longo do curso da **Data Science Academy**, foram adicionados elementos complementares ao dashboard, como indicadores e gráfico de evolução dos Lucros Acumulados, buscando tornar a apresentação dos dados mais visual e facilitar sua interpretação.

Esse processo também fez parte da minha prática de transformar uma visualização básica em um dashboard mais completo e informativo.

##  Principais elementos adicionados

Além da matriz proposta no laboratório, foram incluídos:

* Cards com indicadores financeiros;
* Gráfico de evolução dos Lucros Acumulados;
* Organização visual do dashboard;
* Destaque para indicadores de Ativo Total, Passivo + PL e Patrimônio Líquido.
